# Flutter LAB 5

Adaptive E-Commerce Item Detail Screen.

## Requirements
- Product preview with `Stack` cover image and bookmark badge
- Product title, rating, price, and category badges using `Row` and `Wrap`
- Sticky bottom `Add to Cart` action using `Expanded`
- Responsive layout without RenderFlex overflow

## Run
```bash
flutter pub get
flutter run -d chrome
```
